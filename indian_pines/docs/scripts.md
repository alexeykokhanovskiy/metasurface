# Indian Pines — описание скриптов

## Структура проекта

```
indian_pines/
├── data/
│   ├── raw/          ← Indian_pines_corrected.mat, Indian_pines_gt.mat
│   ├── processed/    ← промежуточные результаты
│   ├── filters/      ← целевые спектры фильтров для обратной задачи
│   └── plots/        ← сохранённые графики
├── src/
│   ├── utils.py
│   ├── explore_dataset.py
│   ├── pca_analysis.py
│   └── save_target_filters.py

    └── scripts.md
```

Все скрипты запускаются из папки `src/`:

```bash
cd indian_pines/src
python <script>.py
```

## utils.py

Общие утилиты загрузки данных, используемые всеми остальными скриптами. Не запускается напрямую.

### Функции

**`load_mat(raw_dir)`**
Загружает `.mat`-файлы из `data/raw/` и возвращает три массива:
- `X` — матрица спектров размером `(n, 200)`, float32, сырые значения отражения
- `y` — метки классов `(n,)`, int16, значения 1–16
- `wavelengths` — центральные длины волн `(200,)` в нанометрах

Длины волн соответствуют стандартной сетке AVIRIS: 220 полос от 400 до 2500 нм, из которых удалены 20 полос с поглощением воды (индексы 103–107, 149–162, 219). Итого 200 полос.

**`split_data(X, y, seed=42)`**
Стратифицированное разбиение 60 / 20 / 20 по классам. Возвращает `X_train, X_val, X_test, y_train, y_val, y_test`.

**`zscore(X_train, X_val, X_test)`**
Z-нормировка по каждой полосе отдельно. Среднее и стандартное отклонение вычисляются **только по обучающей выборке** и применяются к val и test, чтобы исключить утечку данных. Возвращает нормированные массивы и параметры `(mean, std)`.

**`CLASS_NAMES`**
Словарь `{int: str}` с английскими названиями 16 классов Indian Pines.

## explore_dataset.py

Быстрый визуальный осмотр набора данных. Не требует предварительной обработки.

### Запуск

```bash
python explore_dataset.py
```

### Что выводит

**В консоль:**
- Общее число размеченных пикселей
- Число спектральных полос и диапазон длин волн
- Таблица: номер класса, название, количество пикселей

**Графики (последовательно):**

1. **Распределение классов** — столбчатая диаграмма количества пикселей по классам. Наглядно показывает сильный дисбаланс: классы «Соя (мин. обработка)» и «Кукуруза (без вспашки)» содержат на порядок больше пикселей, чем «Овёс» или «Люцерна».

2. **Образцы спектров по классам** — сетка 4×4 подграфиков, по одному на класс. В каждом — 3 случайных спектра из данного класса. Позволяет визуально оценить внутриклассовую изменчивость и межклассовые различия.

## pca_analysis.py

Анализ спектральной размерности данных двумя методами: PCA (для оценки информационного содержания) и NMF (для получения физически реализуемых неотрицательных фильтров).

### Запуск

```bash
python pca_analysis.py           # автоматический выбор N по порогу 99%
python pca_analysis.py --n 3     # зафиксировать N=3
```

### Методы

**PCA (Principal Component Analysis)**
Находит ортогональные линейные проекции, максимизирующие дисперсию. Компоненты могут быть отрицательными — физически нереализуемы как спектры пропускания, но дают теоретическую нижнюю оценку необходимого числа каналов.

**NMF (Non-negative Matrix Factorization)**
Разлагает матрицу спектров на произведение двух неотрицательных матриц. Компоненты не содержат отрицательных значений, что соответствует физическому смыслу пропускания оптического фильтра. Перед подачей в NMF каждая полоса сдвигается так, чтобы минимум по обучающей выборке стал равен нулю; значения val/test обрезаются снизу до 0.

### Что выводит

**В консоль:**
- Число компонент NMF для достижения заданной точности классификации при каждом N

**Графики:**

1. **Кривая дисперсии PCA** (`data/plots/pca_variance.png`) — накопленная объяснённая дисперсия в зависимости от числа компонент. Горизонтальные линии отмечают пороги 90%, 95%, 99%. Вертикальная синяя линия — N=3 (целевое значение).

2. **Точность NMF от числа фильтров** (`data/plots/nmf_accuracy_sweep.png`) — точность Random Forest на val-выборке при числе NMF-компонент от 2 до 10. Показывает точку убывающей отдачи.

3. **Компоненты NMF** (`data/plots/nmf_components_nN.png`) — N спектров фильтров, нормированных к [0, 1]. Это кандидаты на целевые спектры пропускания для метаповерхности.

**Файлы:**
- `data/processed/nmf_filters_nN.npz` — компоненты NMF (нормированные), длины волн

**Итоговая таблица в консоли:**
```
Полный спектр (200 полос) test: 91.3%
NMF N=3 val:                    74.1%
NMF N=3 test:                   73.8%
```

## save_target_filters.py

Финальный скрипт этапа анализа данных. Подбирает NMF для заданного числа фильтров и спектрального диапазона на трёх классах (Соя / Лес / Башни) и сохраняет полученные спектры фильтров в формате, готовом к использованию в задаче обратного проектирования метаповерхности.

### Запуск

```bash
# Предустановленные диапазоны
python save_target_filters.py --n 3 --range vis    # 400–1000 нм
python save_target_filters.py --n 3 --range nir    # 1000–1500 нм
python save_target_filters.py --n 4 --range swir   # 1500–2500 нм
python save_target_filters.py --n 3 --range full   # полный спектр

# Произвольный диапазон
python save_target_filters.py --n 3 --lo 800 --hi 1600
```

### Классы

Используются три класса, объединённые из исходных 16:

| Метка | Исходные классы | Описание |
|-------|----------------|----------|
| 1     | 10, 11, 12     | Соя (все варианты объединены) |
| 2     | 14             | Лес |
| 3     | 16             | Металлические башни |

Сужение до трёх хорошо разделимых классов делает задачу обратного проектирования реалистичной для малого числа фильтров (N=2–4).

### Выходные файлы

**`data/filters/target_filters_N{n}_{range}.npz`**

| Ключ | Форма | Описание |
|------|-------|----------|
| `wavelengths` | `(B,)` float32 | Длины волн в нм для выбранного диапазона |
| `filters` | `(N, B)` float32 | Спектры фильтров, нормированные к [0, 1] |
| `n_filters` | скаляр | Число фильтров N |
| `wl_min` | скаляр | Нижняя граница диапазона, нм |
| `wl_max` | скаляр | Верхняя граница диапазона, нм |

Пример загрузки в задаче обратного проектирования:

```python
import numpy as np
data = np.load("data/filters/target_filters_N3_vis.npz")
wavelengths = data["wavelengths"]   # (B,)
filters     = data["filters"]       # (3, B)  — целевые спектры пропускания
```

**`data/plots/target_filters_N{n}_{range}.png`** — график фильтров для визуальной проверки.
